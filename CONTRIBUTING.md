Projeto mantido por **MK** (@mkhyur). Abra uma issue antes de grandes mudancas.

2. Kotlin/Compose no `manager/`, Rust no `userspace/`, C no `kernel/`.
3. Nao inclua chaves (`*.jks`) nem segredos nos commits.
4. Mantenha cabecalhos de licenca GPL e creditos upstream.
